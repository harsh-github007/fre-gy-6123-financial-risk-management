# Structural credit risk | Ratings migration and the Merton model

The assignment compares ratings-based spread shocks with a structural model in which equity is a call on the firm’s assets.

## Ratings migration

Weight first-order price moves by the transition probabilities. In the two-transition example, the expected price change is −0.1485%.

## Asset volatility

Holding asset value and debt face value fixed, the Merton illustration shows that higher asset volatility raises both equity value and the value of the default put. The implied debt value falls.

## Expected loss

Apply exposure at default × probability of default × loss given default for the one-year example. The report also compares distance to default with observed default frequency and discusses derivative credit exposure.
