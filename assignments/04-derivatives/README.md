# Derivatives | Pricing and hedge risk

The assignment uses replication to price forwards and test put–call parity, then examines exposure and hedging after the trade is entered.

## Forward pricing

Relate the forward price to cash financing and dividends. A rich forward price can be tested with a cash-and-carry trade whose terminal underlying exposure cancels on delivery.

## Counterparty risk

Track replacement value for an OTC contract and compare its evolution with the daily cash settlement of an exchange-traded future.

## Hedge sensitivity

Use delta to size a local option hedge and gamma to assess how it changes when the underlying moves. The report also examines swap duration and the effects of other option Greeks.

## Run the calculations

Reproduces the forward pricing, mark-to-market, and synthetic-forward calculations. The script uses the Python standard library.

```sh
python3 assignments/04-derivatives/derivatives.py
```
